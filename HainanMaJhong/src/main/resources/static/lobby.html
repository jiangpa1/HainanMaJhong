海南麻将 V2.5 更新与优化内容

  • 海南规则引擎：庄/令/底分、打满四风；天胡 / 天听 / 地听 / 报听
  • 底分随连庄乘算（创建底分 × 连庄次数），可设房间底分
  • 新增胡牌模式：有番 / 无番（无番即去掉“有番才能胡”）
  • 杠分可设：明杠 / 补杠 / 暗杠分值
  • 吃后禁打：吃完不可打出能再凑顺子的牌（例 56吃7 不可出 4/7）
  • 房间支持人机补齐：1~3 真人也能开局，电脑照房间规则打
  • 对局结束“再来一轮”：同一房间、战绩续加、金币不清零
  • 战绩明细：展示庄家、当前令、点炮者与点炮牌；杠/花图形化
  • 对局内聊天：快捷短语 / 表情 / 文字输入，昵称旁气泡展示
  • 各家抓到的花牌在桌面上展示
  • 创建房间规则弹窗：手机上可滚动、按钮常驻可见
  • 网页打包适配：禁止缩放、返回键优化、页面不缓存（改后即时生效）
  • 首页与大厅提供“下载 APP”入口

本次小更新

  • 结算口径优化：庄相关笔按“连庄后的当前底分”，闲与闲之间按“房间初始底分”，点炮者追加按“初始底分”
  • 登录页新增“记住用户名和密码”，下次自动回填
  • 大厅“设置”按钮移到右上角，与“关于”并列
  • 大厅底部新增横屏体验提示
  • 局内聊天气泡放大为两倍，更醒目
  • 创建房间规则框在手机竖屏下也完整可见、可滚动
  • 修复：吃后禁打按同花色判断，1、2筒吃3筒不再误禁 9万
  • 修复：多人对局中自家出的牌能正常显示在桌面
  • 一圈判定修正：打满东南西北四风（北风令中开局庄家上家下庄才结束），不再提前收场
  • 报听/天听/地听：天听=自己未出牌(含庄家首轮)、地听=庄家未出第4张前；存在“打出某张仍听”即可报，报听当轮只能打仍听的牌，之后抓到什么打什么
  • 音效系统：背景音乐循环、胡牌音效（优先番型）、吃碰杠/补花/报听/聊天语音均已接入
  • 胡牌大字去掉“点炮”字样；胡牌音效播完才开下一把
  • 设置菜单新增“关闭音乐 / 关闭音效”（音效含 sound_effects 与 voices）
  • 四人座位开局随机分配，进房顺序不再决定座位；下一圈座位不变
  • 天胡/天听/地听 作为番型并入结算与展示（胡牌大字、战绩均显示），且不与平胡叠加
