## 三、怎么读这张表

1. **一次压测一行**；`轮次` 是结果目录名（如 `b200-over`、`long-320-1800`）。
2. **429 不是失败**：它是准入保护按设计拒绝，单独列成 `429` 一栏；`失败` 只统计非 429 的错误。
3. `结果` 列给出 `stopReason`：`null` = 正常跑完；`cpu-over-95-percent-for-60-seconds` = 撞 CPU 护栏；`round-drain-timeout` = 收尾排空超时；`stage-acceptance-failed` = 判据未过（多因可测路由样本不足）。
4. **CPU 为牌局期采样**（`rooms_playing>0`）；不同轮次的机器负载不同，跨轮**不宜直接比较**绝对 CPU。
5. **延迟只含 `outcome=success`**：429 平均耗时反而更高（实测 62.9 ms vs 成功 37.3 ms），混算会扭曲结论。
